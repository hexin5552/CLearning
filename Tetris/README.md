# 俄罗斯方块 Tetris（C语言 Windows控制台版）
> 项目名称：Console Tetris Game
> 作者：Hexin
> 版本：v1.0
> 开发环境：MinGW / GCC，Windows平台，依赖 Windows API、`winmm.lib`（音频）
> 项目结构：多文件模块化开发（头文件分离、系统封装、数据、游戏逻辑解耦）

> ⚠️ 重要限制：仅支持 Windows 系统，依赖 `windows.h`、`conio.h`、`winmm.lib`，Linux / MacOS 无法直接编译运行。

## 📖 项目简介
经典俄罗斯方块控制台复刻项目，采用模块化C语言开发，内置 **3种游戏模式**，支持方块旋转、左右移动、一键落底、暂停、消行计分、段位升级、下一块预览、游戏计时、结束动画、重新开局等完整功能；支持控制台色彩、光标定位、隐藏光标、背景音乐预留接口，附带开场动画与结束ASCII装饰画面。

## 📂 项目文件结构
```
Tetris/

└── README.md       // 项目说明文档（本文档）
```

## 🧱 数据设计说明
### 1. 宏定义（date.h）
```c
#define COL 25      // 窗口总行数
#define TYPE 7      // 方块种类总数（Z、S、L、J、I、T、田字方块）
#define KIND 4      // 每种方块旋转形态数量（最多4种）
#define DATEC 4     // 方块数据数组行数
#define DATEL 4     // 方块数据数组列数
#define LINE 26     // 窗口总列数
```
- `windowsShape[COL][LINE]`：游戏窗口地图数组，`1=墙壁/已落下方块，0=空地`
- `block[TYPE][KIND][DATEC][DATEL]`：三维数组存储全部方块形态，7大类方块，每类4种旋转姿态，4×4网格存储方块点阵

### 2. 方块结构体 BLOCK（game.h）
```c
typedef struct {
    int x, y;        // 方块左上角在控制台的坐标
    int shape;       // 方块种类 0~6
    int status;      // 当前旋转形态 0~3
    int color;       // 方块控制台颜色码
}BLOCK;
```
- `cur_block`：当前正在下落的方块
- `next_block`：右侧预览区的下一个方块

### 3. 全局统计变量
```c
int grade = 0;          // 游戏分数
int level = 1;          // 段位等级
int one, two, three, four;  // 消除1/2/3/4行的次数统计
```

## 🎮 游戏模式介绍
| 模式编号 | 模式名称 | 特性说明 |
| ---- | ---- | ---- |
| 1 | 经典模式 | 方块下落速度较慢（0.65s/帧），方块正常可见，适合新手 |
| 2 | 暴走模式 | 下落速度极快（0.15s/帧），方块可见，考验反应 |
| 3 | 地狱模式 | 下落速度同暴走模式，**方块不渲染显示**，纯记忆挑战 |

## 🎹 操作按键
| 按键 | 功能 |
| ---- | ---- |
| A / ← | 方块左移 |
| D / → | 方块右移 |
| W / ↑ | 方块旋转变形 |
| S / ↓ | 方块缓慢下移一格 |
| Enter | 方块直接落到底部 |
| Space 空格 | 游戏暂停，再次按空格恢复 |

## 🧩 核心游戏流程
1. **开场动画**：彩色标题文字横向滚动动画，按下Enter进入模式选择界面
2. **模式选择**：输入1/2/3，选择对应游戏模式
3. **游戏初始化**：绘制边框、信息面板、生成第一个方块、预生成预览方块
4. **主循环**
    - 非阻塞检测键盘输入，处理移动、旋转、一键落底、暂停
    - 定时器自动下落方块
    - **碰撞检测 crash()**：检测方块移动/旋转后是否撞墙、撞到已经落地的方块
    - 方块落地：`save()` 将方块点阵写入地图数组
    - **消行检测 lineClear()**：遍历地图，判断一行是否填满；满行消除，上方所有行向下掉落
    - 计分：消除1行+10分、2行+40分、3行+60分、4行+80分
    - 自动升级段位，分数越高段位越高
    - 生成新方块，预览区刷新下一块
5. **游戏结束判定**：新方块生成瞬间就发生碰撞（顶部堆满）
    - 播放结束动画
    - 展示结算面板：总分、段位、消除行数统计、游玩时长、ASCII装饰画
    - 支持 Y 重新开局 / N 退出游戏

## 🖼️ 控制台渲染与系统封装（mywindows模块）
封装Windows原生控制台API，实现功能：
1. `initHandle()`：初始化控制台句柄，设置控制台编码UTF-8，防止方块乱码，隐藏光标
2. `setColor()`：修改控制台文字前景色
3. `setPos()` / `setPosASCII()`：两种光标定位接口（适配双倍宽方块字符、ASCII装饰画）
4. `hideCursor()`：隐藏闪烁光标，优化画面观感

> 字符说明：`■` 作为方块绘制字符，`□` 用于侧边面板装饰

## 🛠️ 编译命令（MinGW gcc）
```bash
gcc main.c game.c mywindows.c -o tetris.exe -lwinmm
```
> `-lwinmm` 链接多媒体库，用于 mciSendString 音频播放接口
运行：
```bash
./tetris.exe
```

## 📝 已知限制 & 拓展方向
1. 平台绑定Windows，依赖win32控制台API，跨平台需要重写输入、光标、颜色模块
2. 地狱模式仅隐藏方块渲染，碰撞逻辑不变
3. 背景音乐路径硬编码，需要自行修改音频路径启用
4. 无存档功能，退出后分数、段位不保存
5. 没有自定义背景、自定义方块皮肤功能
6. 清屏使用 `system("cls")`，高速模式下存在轻微画面闪烁
