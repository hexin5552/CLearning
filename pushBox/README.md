# 推箱子 Sokoban（C语言 · Windows控制台版）
> 项目名称：pushBox Game
> 开发环境：MinGW / GCC，Windows平台（依赖 `conio.h`、`stdlib.h`）
> 作者：Hexin
> 版本：v1.0

## 📖 项目简介
基于C语言实现的控制台推箱子小游戏，一共内置5个关卡。
玩家使用 `W/A/S/D` 控制人物移动，把所有箱子推到目标点位上即可通关，自动进入下一关；全部关卡通关后游戏结束。
> ⚠️ 平台限制：仅支持 Windows 编译运行，Linux / Mac 无 `conio.h` 头文件，无法直接使用 `getch()`。

## 🧱 地图元素定义
地图使用三维数组 `Map[关卡数][行][列]` 存储，每个格子数字含义：
| 数值 | 含义 | 显示字符 |
| ---- | ---- | ---- |
| 0 | 空地 | 空格 |
| 1 | 墙壁（不可穿过） | ██ |
| 3 | 目标点（终点） | 终 |
| 4 | 箱子 | 箱 |
| 6 | 玩家角色 | 人 |
| 7 | 箱子 + 目标点重合（箱子到位） | 箱 |
| 9 | 玩家 + 目标点重合（人站在终点上） | 人 |

> 核心规则：箱子只能推，不能拉；箱子后方是墙或者另一个箱子时，无法推动。

## 📌 宏定义与全局变量
```c
#define COL 8    // 地图行数
#define LINE 8   // 地图列数
#define NUM 5    // 总关卡数量
int level = 1;   // 当前关卡，从第1关开始
int i, j;        // 遍历、定位玩家坐标临时变量
// 三维地图：[关卡][行][列]
int Map[NUM][COL][LINE] = { /* 5关地图数据 */ };
```
> 每一关都是 8×8 大小地图，内置5套预设关卡布局。

## 🧩 函数清单与功能说明
| 函数 | 功能描述 |
| ---- | ---- |
| `void printMap(int Map[NUM][COL][LINE])` | 绘制当前关卡地图，循环遍历数组，根据数值打印对应字符 |
| `void getPosition(int Map[NUM][COL][LINE])` | 查找玩家坐标，接收键盘输入，处理人物移动、推箱子逻辑 |
| `int getWin(void)` | 通关判定函数：统计所有已经到位的箱子（值=7），满足条件返回通关标记 |
| `main()` | 程序入口，关卡循环：当前关卡未通关就持续渲染+接收操作，通关后关卡号+1，直到全部关卡打完 |

## 🎮 核心控制流程
### 1. 按键控制
- `W`：向上移动（行号 i-1）
- `S`：向下移动（行号 i+1）
- `A`：向左移动（列号 j-1）
- `D`：向右移动（列号 j+1）
> 使用 `getch()` 无回显读取按键，不需要回车确认；不阻塞画面循环。

### 2. 移动判定规则（核心逻辑）
1. **前方是空地(0) 或者 目标点(3)**：玩家可以直接走过去
    - 新位置加上玩家标记 `+6`
    - 原位置减去玩家标记 `-6`
2. **前方是箱子(4) / 已经在目标上的箱子(7)**：需要再判断箱子下一格
    - 如果箱子的下一格是空地(0) / 目标点(3)：箱子可以被推动
        - 箱子移动到下一格
        - 玩家移动到箱子原来的位置
    - 如果箱子后面是墙或者别的箱子：**无法推动，本次移动无效**
> 数值叠加逻辑：
> - 人站在终点：`3 + 6 = 9`
> - 箱子推到终点：`3 + 4 = 7`

### 3. 通关判定 `getWin()`
遍历整张地图，统计值为 `7`（箱子在目标点）的格子数量。
本项目每一关固定 **4个目标点位**，当到位箱子数量等于4时，判定通关，跳出本局循环，进入下一关。
```c
int count = 0;
for (i = 0; i < COL; i++)
    for (j = 0; j < LINE; j++)
        if (Map[level][i][j] == 7)
            count++;
return count == 4 ? 4 : 0;
```

### 4. 关卡跳转逻辑
外层 `while(level <= NUM)` 循环控制关卡：
- 本局内循环：不断刷新地图、接收移动、判断是否通关
- 通关后打印 `通关!!`，清屏，`level++` 加载下一关
- 当 `level > 5`，所有关卡打完，程序结束

## 🖼️ 渲染原理
- 每次操作完成后调用 `system("cls")` 清屏，重新打印整张8×8地图
- 双重for循环遍历二维地图，switch匹配数值，打印对应符号
- 墙壁使用 `██` 方块，终点“终”，箱子“箱”，玩家“人”

## 🛠️ 编译&运行教程
### 编译命令（MinGW gcc）
```bash
gcc sokoban.c -o sokoban.exe
```
### 运行
```bash
./sokoban.exe
```
> 打开exe，在控制台内使用 W S A D 操作游玩。

## 📝 已知限制 & 待拓展方向
1. 仅 Windows 可用，依赖 `conio.h` 的 `getch()`

4. 没有游戏结束提示、通关全部关卡的收尾提示
